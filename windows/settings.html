How to connect Codex

  1. Install the hook here (it also enables hooks in Codex's config.toml).
  2. Open Codex CLI and run /hooks.
  3. Press t to Trust the AgentPet hook.
  4. Quit and reopen Codex (both the CLI and the desktop app).
